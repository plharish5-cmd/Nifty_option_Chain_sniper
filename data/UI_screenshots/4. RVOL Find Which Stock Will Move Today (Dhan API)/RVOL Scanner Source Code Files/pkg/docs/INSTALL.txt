RVOL SCANNER — INSTALLATION
=============================================================================

WHAT YOU NEED
  - Windows 10 or 11, 64-bit
  - A Dhan account with API access (the data API — no PIN needed)
  - Nothing else. No Python, no installer, no database.

STEP 1 — PUT IT SOMEWHERE WRITABLE
  Copy the folder to somewhere like C:\RVOLScanner or your Desktop.
  Do NOT put it in C:\Program Files — Windows makes that read-only for normal
  users and the program needs to write config.json and its cache beside itself.

STEP 2 — RUN IT
  Double-click RVOLScanner.exe. Your browser opens at http://127.0.0.1:7710
  There is no console window. If Windows SmartScreen warns about an unknown
  publisher, choose "More info" then "Run anyway" — the file is unsigned
  because code-signing certificates cost money.

STEP 3 — PASTE YOUR TOKEN
  Get it from: Dhan -> Profile -> DhanHQ Trading APIs -> Access Token.
  Paste it into Setup and press Save. The client ID is read from the token
  itself, so you do not need to type it.

  Dhan tokens EXPIRE — usually within a day. When the scanner stops working,
  this is almost always why, and the Setup page tells you the exact expiry
  date rather than making you guess.

STEP 4 — SCAN
  Press Scan. Drag the time slider to scan as of any moment in the session.
  Click a stock to see today's cumulative volume against its usual pace: the
  shaded gap between the two lines IS the RVOL.

HOW LONG IT TAKES
  The first scan makes one API call per symbol (50 for the Nifty 50), paced so
  Dhan does not rate-limit you — about 20 seconds. After that it is cached for
  15 minutes and returns instantly.

IF SOMETHING GOES WRONG
  rvolscanner.log sits next to the program and says what failed.

  "token expired"        generate a new one on Dhan, paste it in Setup
  scan returns nothing   markets closed, or the date has no session
  fewer stocks than      rate limiting; wait a moment and scan again, the
  expected               cache keeps whatever already succeeded

UNINSTALLING
  Delete the folder. Nothing is written anywhere else.
