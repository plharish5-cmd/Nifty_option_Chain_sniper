RVOL Scanner — Setup

Paste your Dhan token, choose what to scan, and you are done. Everything stays on this computer.

1Dhan access token

Dhan → Profile → DhanHQ Trading APIs → Access Token. Saved in config.json next to the program and sent only to Dhan's own API. The client ID is read out of the token itself, so you do not need to type it.

2What to scan

The Nifty 50 is bundled with its security IDs. Choose a smaller list if you want a faster scan — every symbol is one API call the first time.

3How it is measured

Sensible defaults. Change only if you know why.

The turnover floor is in rupees, not shares, on purpose: MARUTI trading 29,000 shares is ₹40 crore of real business, while a ₹50 stock doing 1 lakh shares is only ₹50 lakh. A share floor would throw away every expensive stock.
